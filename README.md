
# FINE3300-2026-A1: Exchange Rate Calculator

Converts monetary amounts between Canadian dollars (CAD) and US dollars (USD) using the latest exchange rate from Bank of Canada data.

## Files
- `ExchangeRates.py`: my own implementation (Part 1, no AI)
- `ExchangeRatesAI.py`: AI-generated implementation (Part 2)
- `BankOfCanadaExchangeRate.2026.csv`: Bank of Canada exchange rate data

## How to Run
    python3 ExchangeRates.py
    python3 ExchangeRatesAI.py

## Example Output
    Enter amount: 100000
    Convert from (USD or CAD): USD
    Convert to (USD or CAD): CAD
    $100,000.00 USD = $139,780.00 CAD
